アップロードした kickboxingTechniques の技データを、現在のアプリの技一覧に統合してください。



要件：



1. 既存の techniques 配列を、アップロードした kickboxingTechniques の内容に置き換える


2. 現在のHTML/CSS/JavaScript構成で動くようにする


3. export const は使わず、通常の const kickboxingTechniques = [...] として扱う


4. 技一覧では以下を表示する


- 技名


- カテゴリ


- 難易度


- 推定消費カロリー kcalPerMin


5. カテゴリで絞り込みできるようにする


- punch


- kick_low


- kick_middle


- kick_high


- knee


- defense


- footwork


- feint


- counter


- combo


6. 検索機能も追加する


7. 技をクリックしたら「コンボ作成エリア」に追加できるようにする



コンボ作成機能：



1. ゲームのスキルビルドのように、技を順番に選んでコンボを作る


2. 選んだ技を横並び、または矢印つきで表示する


例：


ジャブ → ストレート → 左フック → ローキック


3. 選んだ技の合計難易度を表示する


4. 推定カロリーも合計表示する


5. 「コンボ名」を入力して保存できるようにする


6. 保存したコンボは localStorage に保存する


7. 保存済みコンボ一覧を表示する


8. コンボから技を1つ削除できるようにする


9. コンボをリセットできるようにする



UI方針：



1. スマホアプリ風


2. 黒基調


3. 技カードはゲームのスキルカード風


4. 難易度は★で表示


5. カテゴリごとにタグ表示


6. コンボ作成エリアは「ビルドスロット」っぽくする



注意：



1. AI機能は使わない


2. Firebaseは使わない


3. HTML/CSS/JavaScript/localStorageだけで実装


4. 現在のコードを直接編集してください
